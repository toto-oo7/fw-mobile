# Source Code Pro

英文和数字使用 Source Code Pro，保留原有中文系统字体回退。Web 构建只启用 U+0000–024F，字号、字距和原文大小写保持原样。

字体来源：Supabase Studio 官方仓库 `apps/studio/fonts/source-code-pro/SourceCodePro-Variable.woff2`，与其字体声明一致。许可为 Adobe Source Code Pro 的 SIL Open Font License 1.1，随附 `OFL.txt`。

Windows 版随程序加载 Adobe 官方 Regular、Medium、Semibold TTF；不安装到操作系统。
